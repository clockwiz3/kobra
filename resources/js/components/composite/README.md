# composite/ — сложносоставные виджеты

Второй ярус библиотеки компонентов Kobra. Здесь живут **доменно-агностичные
составные виджеты**, которые собираются из примитивов `ui/` и/или несут
собственную нетривиальную логику отрисовки.

Планируемые жильцы (расширяется): **Gantt-диаграмма**, **Calendar**, таймлайн,
канбан-shell и т.п.

## Правила

- **Состав:** можно (и нужно) переиспользовать примитивы из `@/components/ui`
  (`BaseModal`, `BaseButton`, `BaseCheckbox`, …). Примитивы про composite не знают —
  зависимость только в одну сторону: `composite/ → ui/`.
- **Темизация:** визуальные стили — классами из `resources/css/themes.css`
  с поддержкой всех трёх тем (`dark` / `light` / `pixel`) на общих токенах
  (`--surface`, `--border`, `--grad`, `--accent`, `--r-*`, `--shadow`, …).
  Pixel-тема — жёсткая геометрия (`--r-*: 0`, offset-тени, border 3–4px).
- **API:** `script setup` + `lang="ts"`; типизированные `defineProps` /
  `defineModel` / `defineEmits`; данные наружу — через слоты/события, без скрытого
  глобального состояния.
- **a11y:** клавиатура, `role`/`aria`, фокус-менеджмент — обязательны
  (см. как сделано в `ui/BaseModal.vue`).
- **Логирование:** через `@/composables/useLogger` на уровне взаимодействий
  (открытие/выбор/перетаскивание), не на каждый ререндер.

## Экспорт

Когда здесь появятся компоненты — добавить barrel `composite/index.ts`
по образцу `ui/index.ts` и реэкспортить именованно.
